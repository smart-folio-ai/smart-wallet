Contraste medido

Calculado par a par pela fórmula da WCAG, não estimado no olho. O mínimo é 4,5:1 para texto corrido e 3:1 para elementos de interface e texto grande.

Uma regra sai daí. No tema escuro, a marca sobre o fundo mede 3,91:1 — passa para botão, borda, ícone e texto grande, mas não para texto corrido pequeno. Então azul de marca não vira cor de parágrafo no escuro. No claro isso não é problema: 4,78:1.

Contrastes calculados sobre os canais HSL exatos desta proposta. Os quadros de exemplo usam as mesmas cores, então o que você vê é o que vai para o index.css.
